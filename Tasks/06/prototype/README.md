# Прототип мониторинга очереди обмена с 1С

Демонстрационный инструмент на Python 3, без сторонних библиотек. Все данные в `data/queue_snapshot.json` выдуманы.

## Запуск

Из этой папки:

```bash
python3 monitor.py --input data/queue_snapshot.json --config config.json
```

Сохранить отчёт в файл:

```bash
python3 monitor.py --input data/queue_snapshot.json --config config.json --output examples/report.txt
```

## Пороги

Пороги настраиваются в `config.json`: максимальный возраст ожидающего задания, возраст последнего успешного обмена, число ожидающих, число ошибочных заданий и количество повторных попыток.

## Код завершения

- `0` — `OK`;
- `1` — `WARNING`;
- `2` — `CRITICAL`;
- `3` — ошибка чтения/валидации данных.

Код завершения позволяет подключить проверку к cron или системе мониторинга. В этой демонстрации скрипт читает локальный JSON и не подключается к реальной БД.
